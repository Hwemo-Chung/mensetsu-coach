# T2 — 中途採用・職業紹介・転職統計

作成 2026-11-02。アクセス日 2026-11-02。上位文書: `README.md`。

## 2. 解釈

- **日本の中途採用市場は506万件規模ですが、この数字はホワイトカラー・外国人・面接コーチングの市場ではありません。** パートタイム・現場職・非正規が含まれます。一般労働者のみで見ると318万件です。マーケティングで「506万人が転職する」と書くと誇張になります。
- **有効求人倍率1.20は全職種の平均で、正社員は0.99です。** 「求人が多い」という印象は職種によって異なります。外国人ホワイトカラー市場の需給をこの数字で代表させることはできません。
- **職業紹介の手数料103万円は常用就職全体の平均です。** 外国人の技人国のみの手数料ではありません。ただし技人国の平均月給306,500円 × 12か月 × 30~35% = 約110万~129万円と近い水準であるという点は、**仮説**としては使えます。[Medium]
- **5.5%は転職希望です。** 実際の転職率や求職活動率ではありません。市場規模を計算する際に、この値を「年間転職者数」に置き換えて使ってはいけません。
- **30~35%は法定料率ではありません。** 民間の慣行の説明です。契約書・手数料規定は事業所ごとに異なります。

## 3. 中途採用で確認できなかったこと

以下の項目は日本で広く行われている慣行として語られますが、今回の調査では**公的な一次資料で一般化できませんでした。** 製品がこれらの内容を事実のように述べてはいけません。

| 項目 | 状態 | 理由 |
|---|---|---|
| 転職エージェントの標準フロー（登録→面談→推薦→面接→内定→入社） | 未確認 | 公的資料は職業紹介の制度・統計のみを扱い、事業所ごとのフローは公開資料ではない |
| スカウト対応（返信期限、断り方） | 未確認 | 公的な規範なし |
| 年収交渉（希望年収の記載、交渉のタイミング） | 未確認 | 公的な規範なし。民間コンサルティングの助言のみ |
| 一次/二次/最終面接の評価軸 | 未確認 | 企業ごとに非公開。公的統計なし |
| 退職の通知期限（2週間前など） | 未確認 | 民法第627条は期間の定めのない雇用の解約の申入れについて定めているが、会社の規程・業界の慣行と異なる場合がある。今回の調査では条文を直接確認していない |
| 職務経歴書への年収記載の有無 | 未確認 | 公的な様式は年収の記載を求めていない。企業ごとの要求 |
| 英文レジュメ → 日本式への変換 | 未確認 | 公的な規範なし |

## 4. コーチングに使える文（草案）

- 「日本の中途採用は1年に500万件以上の入職がありますが、その数字にはパートタイム・現場職が含まれます。外国人ホワイトカラーの市場はそれよりはるかに小さいです。」
- 「職業紹介の手数料は全体平均103万円ですが、これは外国人専用の数値ではありません。エージェントとの契約条件を直接確認してください。」
- 「転職希望の回答は6.1%（技人国5.5%）です。実際に転職する割合と同じではありません。」
- 「面接段階の名称（1次/2次/最終）は企業ごとに異なります。求人票・エージェントの案内で確認してください。」

## 5. 製品に反映する際の注意

- `T2` は面接回答のルールではなく、**市場・制度の文脈**です。面接コーチの画面に「506万人」のような数字を入れると、ユーザーにとって無意味か、誤解を招きます。
- B2B の価値計算に103万円を使う際は、「常用就職全体の平均」であることを明記する必要があります。
- 5.5%を市場規模として使う際は、「転職希望」のラベルを必ず付ける必要があります。
