# KR-K5 — 日本人の韓国企業面接：繰り返される失敗パターン（コミュニティ内部リサーチ）

作成・アクセス日 2026-11-02。用途：日本人求職者が韓国企業の面接（面接言語は韓国語、解説は日本語）を準備するための新規国別パック（`kr`）の候補。脚注 `[K5-nn]` は `KR-K5.claims.json` の id です。脚注のない文は解釈・設計上の提案です。
原文URL・原文の表現はリポジトリに置いておらず、リポジトリ外の作業メモにのみあります。すべての出典は kind: private（事実の要約のみ）です。

## 要約

1. 公開ウェブ上の独立した8件の投稿（個人ブログ・note の体験談3~4件、メンタリングの伝聞2件、採用側の対談1件、業者の解説1件）を読み、2件以上で重なるパターン8つのみを残しました。X は調査していません。
2. 最も強いパターン：動機の質問（「なぜ韓国、なぜこの会社」）[K5-01]、「今何ができるか」[K5-02]、ポートフォリオ・PPT [K5-06]、面接言語・回数のばらつき [K5-07]。
3. 限界：標本が小さく（8件）、大半は2018~2024年の記事です。体験報告は韓国の大学卒業・留学後に応募した事例が中心のため、日本から直接応募する求職者にはそのまま当てはまらない可能性があります。合格・不合格の「原因」の大半は筆者の解釈であり、面接官の確認を経ていません。
4. 日本語話者に特有の韓国語の誤り（言語転移）のパターンについては、この調査では根拠を得られませんでした。下記の未確認に仮説としてのみ記載しました。

## 確認された事実

- 日本人応募者は「なぜ日本ではなく韓国なのか」「なぜこの会社なのか」「なぜ韓国語を勉強したのか」を繰り返し聞かれ、韓国文化への好感や漠然とした会社選びは弱い回答として扱われます。[K5-01]
- 面接官は入社後すぐに貢献できることと具体的な成果を見ており、性格・成長の話が中心の回答は不利です。[K5-02]
- ビザの状況と長期勤続の意思を尋ねられる、または応募者から先に確認すべき場面がよくあり、率直に明かした側が好意的な反応を得た事例と、スポンサーの約束が不明確でオファーが撤回された事例の両方があります。[K5-03]
- 集団に合わせるという回答や消極的な態度は主体性の不足と受け取られることがあり、仮定の状況で反対意見を言えるかを問う質問が出ます。[K5-04]
- 語学力だけを強みとして打ち出すと、差別化が困難です。[K5-05]
- ポートフォリオ（PPT）が言葉で足りない部分を補い、2次で約30分のPPTグループ課題が出ることがあり、韓国式のポートフォリオは読みやすい履歴書に近いものです。[K5-06]
- 面接言語はすべて韓国語、日本語・韓国語の併用など会社ごとに異なり、3~4回目にAI性格検査・グループ課題が含まれ、職務ごとに求められる韓国語の水準（TOPIK 上級~未確認）が異なります。[K5-07]
- 服装はスタートアップ・中小企業では比較的自由で、大企業は格式を重んじます。[K5-08]

## パック候補

各パターン：状況 → 原因 → 教訓 → コーチの発話（ko, ja）。注入テキストは韓国語です。

**P1 動機の回答がありきたり [K5-01]**
- 状況：'왜 한국에서 일하려 하나요?'（なぜ韓国で働こうとするのですか。）に、韓国文化が好きだとだけ答える。
- 原因：面接官は定着・成果の可能性を見ているのに、回答が趣味のレベルにとどまる。
- 教訓：特定の職務・会社と結びついた理由1つ＋根拠1つ。
- ko: "한국이 좋아서라는 이유는 빼고, 이 회사의 어떤 일에 제 경험이 쓰이는지 한 문장으로 먼저 말씀하세요."（韓国が好きだからという理由は外し、この会社のどの仕事に自分の経験が活きるかを、まず一文で話してください。）
- ja: 「韓国が好きだから」ではなく、この会社のどの仕事に自分の経験が活きるかを最初の一文で言いましょう。

**P2 「今できる仕事」がない [K5-02][K5-05]**
- 状況：性格・誠実さを中心に答え、日本語能力を唯一の強みに据える。
- 原因：採用側は即戦力と具体的な結果を確認しようとしている。
- 教訓：能力1つ＋数値・成果物1つ。
- ko: "성격 설명 대신 입사 직후 하게 될 업무 하나와 지난 성과 숫자 하나를 말씀하세요."（性格の説明の代わりに、入社直後に担当する業務を一つと、過去の成果の数字を一つ話してください。）
- ja: 性格の説明ではなく、入社直後に担当する業務を一つと、過去の成果の数字を一つ言いましょう。

**P3 ビザ・勤続意思への準備不足 [K5-03]**
- 状況：在留資格や今後何年働く計画かを質問され、言葉を濁す。
- 原因：会社はビザ支援の費用・リスクと定着の意思を確認しようとしている。
- 教訓：現在の在留資格と希望する資格、勤続計画を数字で整理して先に明かし、会社のスポンサー経験を質問する。
- ko: "현재 체류자격과 희망 자격을 먼저 말씀하시고, 비자 지원 경험이 있는지 정중하게 질문하세요."（現在の在留資格と希望の資格を先に話し、ビザ支援の経験があるかを丁寧に質問してください。）
- ja: 現在の在留資格と希望の資格を先に伝え、ビザ支援の実績があるかを丁寧に質問しましょう。

**P4 意見なしに合わせる回答 [K5-04]**
- 状況：反対意見を言えるかという質問に、'팀에 맞추겠습니다'（チームに合わせます）と答える。
- 原因：面接官は、スピードの速いチームで意見を出す人かどうかを確認している。
- 教訓：立場 → 根拠1つ → 合意の方法、の順序。
- ko: "먼저 제 의견을 한 문장으로 말하고, 근거를 하나 대고, 마지막에 팀과 맞추는 방법을 덧붙이세요."（まず自分の意見を一文で述べ、根拠を一つ挙げ、最後にチームと合わせる方法を添えてください。）
- ja: まず自分の意見を一文で述べ、根拠を一つ挙げ、最後にチームとの調整方法を添えましょう。

**P5 口頭だけで勝負 [K5-06]**
- 状況：韓国語の足りない部分を言葉で埋めようとして、回答が長くなる。
- 原因：韓国の面接では、PPT・ポートフォリオを補助手段としてよく使う。
- 教訓：履歴書型1~2枚のポートフォリオと、30分のPPT課題の練習。
- ko: "말이 막히는 부분은 자료를 보여 주며 설명하세요. 포트폴리오는 1~2장으로 읽기 쉽게 정리해 두세요."（言葉に詰まる部分は資料を見せながら説明してください。ポートフォリオは1~2枚で読みやすく整理しておいてください。）
- ja: 言葉に詰まる部分は資料を見せて説明しましょう。ポートフォリオは1〜2枚で読みやすく整理します。

**P6 面接形式のばらつき [K5-07][K5-08]**
- 状況：日本式のスーツ面接だけを想定し、回数・言語・服装を確認しない。
- 教訓：応募受付時に、面接言語、回数、課題の有無、服装を問い合わせる。
- ko: "일정 확인 메일에서 면접 언어와 회차, 과제 여부를 함께 질문하세요."（日程確認のメールで、面接言語と回数、課題の有無を併せて質問してください。）
- ja: 日程確認のメールで、面接の言語・回数・課題の有無を併せて質問しましょう。

文化ノート候補(ko)："면접관은 학습 중이라는 말보다 지금 할 수 있다는 근거를 먼저 듣고 싶어 합니다."（面接官は、学習中だという言葉よりも、今できるという根拠を先に聞きたがっています。）[K5-02]
質問分類の候補：動機（なぜ韓国／なぜこの会社）、即時の貢献、意見表明、ビザ・勤続、課題（PPT）。デイリー質問の候補(ko)："왜 일본이 아니라 한국에서 일하려 하시나요?"（なぜ日本ではなく韓国で働こうとされるのですか。）、"입사하면 첫 달에 무엇을 하시겠습니까?"（入社したら最初の月に何をされますか。）、"팀과 의견이 다르면 어떻게 하시겠습니까?"（チームと意見が異なったらどうされますか。）、"현재 체류자격과 앞으로 계획을 말씀해 주세요."（現在の在留資格と今後の計画をお聞かせください。）
