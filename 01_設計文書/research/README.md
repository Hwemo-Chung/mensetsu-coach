- **民間資料は要約のみ**：事実・慣行の要約と、独自に作成した例文だけを使います。原文の転載はしません。
- **出身差のルールは、独立した出典2つ以上または公的出典1つ**がある場合のみ採用します。なければ `未確認`。
- **すべての数値に母集団・定義・時点・出典・信頼度**を付けます。
- **推定は推定と明記**します。`[Medium]`は二次資料・合理的推論、`[Low]`は根拠のある仮説、`[Unknown]`は確認不可。

## 4. 今回のパスで採用しなかったもの

- **出身別の面接行動ルール**：公的統計なし。民間ブログ・Reddit の事例には代表性がない。
- **年収交渉・スカウト対応・一次/二次/最終の評価軸**：日本の公的資料から一般化できる規範が見つからなかった。
- **英文レジュメ → 日本式への変換**：公的規範なし。
- **STAR/PREP が日本の標準だという主張**：グローバルな民間ツールのフレーム。日本の公的資料は4文型について述べていない。
- **内定辞退のマナー（何日前までに連絡するか等）**：公的資料なし。
- **紹介手数料30~35%が法定料率だという主張**：民間の慣行。法定料率ではない。
- **「日本のサービスには母語でのフィードバックがない」**：不在の証明は不可能。「確認した範囲では」とのみ表記。

## 5. 製品反映の提案（要約）

- `T3`・`T4` の公的規範は**ルール候補**としてすぐに使えます。ただし、`packs/jp.json` は人が承認した後に別作業で行います。

## 7. RESEARCH-PRD との違い

`RESEARCH-PRD.md` は9つの調査文書 + `jp-draft-v2.json` + 38のエージェントを計画していました。今回のパスは以下の理由で縮小しました。

- 出身別の5文書は根拠がないため、1つに統合しました。文書数を埋めるために内容を作ることはしていません。
- （最初のパスの時点では）`jp-draft-v2.json` は作成していませんでした。**その後の R1 パス（2026-11-02）で、R1 候補だけで草案を作成しました** — §3 索引と `SUMMARY.md` を参照してください。`T3`・`T4` の候補はその草案に含まれていません。
- 38のエージェントの代わりに、公的一次資料を直接閲覧しました。コストを抑え、検証可能性を高めました。
