# R1-C2 — 韓国語話者の日本語面接発話：言語間干渉パターン

作成 2026-11-02。アクセス日 2026-11-02。上位文書：`../RESEARCH-PRD.md` §2.1 C2、§3、§4.1。先行文書：`T4-interview.md`（敬語 T4-13~17）。
主張ごとに `R1-C2.claims.json` の id を付しました。規則は**言語転移パターン**としてのみ記述し、話者集団の傾向としては記述しません。

## 要約

- 候補 `correction_rules` 6件のうち、**第1次マージ推奨は3件**です：`rep-sasete-itadaku`（公的根拠）、`rep-uchi-keishou`（公的規範＋転移根拠 直接1件[c2-06]・補助2件[c2-07, c2-08]）、`rep-onsha-spoken`（民間2件）。
- 第2次候補は3件です：`rep-yakushoku-sama`（民間2件）、`rep-daijoubu-kahi`（民間2件、**C2 転移規則ではなく共通規則**）、`rep-yohi`（学術1件、標本2名）。
- 出典により**韓国語からの転移が確認できたのは2点のみ**です。① 自分側の人物に対する敬語（絶対敬語 対 相対敬語）② 漢字語をそのまま置き換える、または助詞を韓国語の意味で選ぶ誤用カテゴリー。②は韓国語母語の標本2名で観察されたもので、漢字語圏全般に当てはまる可能性があります。残りの規則は日本語の規範・慣行としてのみ根拠があります。「〜させていただく」の多用、貴社、役職+様、大丈夫です、頑張ります がこれに該当します。韓国語側の機制（〜드리겠습니다（〜いたします）、귀사（貴社）、부장님（部長様）、괜찮습니다（大丈夫です）、열심히 하겠습니다（頑張ります））は**未確認**です。
- 制約：JAIRO Cloud 系リポジトリ（`*.repo.nii.ac.jp`）が 2026-10-28 からメンテナンスのため開けませんでした。そのため同系統の論文（琉球大 兼本 1996、二松學舍 塩田、神奈川大 高木・尹 など）は本文を確認できていません。
- `packs/jp.json` の既存規則との重複：漢字語 false friend 3件（`rep-touka`、`rep-shuchu`、`rep-shisan`）がすでにあります。今回は**出典のある新しい語を見つけられなかった**ため、個別の語の規則は追加していません。

## 確認された事実

### 1. 「〜させていただく」
- 「(さ)せていただく」は基本的に2つの条件があるときに使います。ア) 相手の許可を受けて行う行為、イ) それによって恩恵を受けるという事実や気持ち。2つの条件をどの程度満たすかによって、適切にも不適切にもなります [c2-01]。
- 許可の条件がなければ「〜いたします」のほうが簡潔です。自己紹介の「卒業させていただきました」型は、条件がないと感じられれば不適切と判断されます [c2-02]。
- この規範の出典は文化庁の公的資料であり、利用条件は公共データ利用規約（第1.0版）準拠・CC BY 4.0 互換です [c2-18]。

### 2. 自分側の人物の敬語（身内・ウチ）
- 取引先に自社の部長のことを話すときは、ウチ扱いとして「田中」「部長の田中」と呼べます。「田中部長」はウチ扱いにならないため不適切です [c2-04]。
- 社外の人がいる場では、ウチである社長を立てないほうがよいとされます [c2-05]。
- 韓国語には、外部の人に自分の家族や会社の目上の人のことを話すときにも敬語を使えるという違いがあると説明されています [c2-06]。日韓通訳教育でも、絶対敬語 対 相対敬語の違いを注意点として扱っています [c2-07]。日本側では、家族をウチとみなす規則が敬語選択の基準として分析されています [c2-08]。
- `T4-interview.md` T4-15 は、自分側の行為に尊敬語を使わない規則（動詞）をすでに扱っています。本文書が加えるのは2点です。① **呼称**（名前+役職）を扱います。② **転移根拠**を付します。
- 転移根拠の強さ：韓国語と日本語を直接対比した記述は [c2-06] の1件です。[c2-07] は教育報告の中の一文です。[c2-08] は日本語側の規則の記述で、転移を直接示す根拠ではありません。
- ステレオタイプテスト：置換 — 出身を入れ替えると真になりません（[c2-06] は韓国語の特徴として記述しています）。欠損 — `reason` は日本語の規範のみを記し、出身に言及しないため、候補者の未熟さを含意しません。
- 範囲の注意：指針が扱うのは**現職**の上司を外部に話す場面です。**前職**の上司を面接官に話す場面は指針に直接は出てきません（下記「未確認」参照）。

### 3. 御社・貴社
- 面接・電話など話すときは御社、メール・書類など書くときは貴社を使うという案内が、独立した民間出典2か所で一致しています [c2-10][c2-11]。
- 「御社様」のように敬称を重ねると誤りだと案内しています [c2-11]。
- 応募者は個人として話すため、面接で現職を弊社・当社と呼ばないという案内があります。これは単一出典です [c2-12]。

### 4. 役職名+様
- 指針は二重敬語を「一つの語について、同じ種類の敬語を二重に使ったもの」と定義しています。役職名+様はこの定義では直接扱われていません [c2-03]。
- 「社長様」「部長様」を二重敬称とみなして避けるようにという案内が、民間2か所で一致しています [c2-13][c2-14]。
- 話すときは「○○社長」または「社長の○○様」を推奨しています。面接では「○○社長」が最も無難で、「○○様」も可能だとしています [c2-13]。

### 5. 「大丈夫です」
- 「大丈夫です」は断りと承諾の両方に使われます。そのため文脈がなければ意味が不明確です [c2-16]。
- 断りの用法は、承諾と受け取った聞き手との誤解事例を生んでいます。明鏡国語辞典はこの用法を本来は不適切と記しています [c2-15]。
- 2つの出典はいずれも**日本語母語話者**の用法を扱っています。したがってこの規則は C2 転移規則ではなく、面接の共通規則です。

### 6. 漢字語直訳カテゴリー（韓国語母語の標本で観察）・助詞の転移
- ステレオタイプテスト：置換 — 漢字語の直訳は中国語話者など漢字語圏の学習者にも当てはまる可能性があります。そのため「韓国語干渉」ではなく「漢字語圏転移」と表記します。欠損 — `rep-yohi` の `reason` は日本語側の自然さのみを記します。
- 韓国語母語の学習者2名の発話誤用分類に、2つのカテゴリーがあります。「韓国語の漢語をそのまま直訳」（例：成功与否 → 成功したかどうか）と「助詞の韓国語意味の影響」です [c2-09]。
- 標本が2名で、初級段階を対象とした1997年の研究であるため、カテゴリーが存在することの根拠にすぎず、頻度の根拠ではありません [c2-09]。

### 7. 「頑張ります」
- 「頑張ります」は抽象的で根拠がないと受け取られる可能性があります。どのように努力し、何で成果を出すのかを話すようにという案内があります [c2-17]。この表現を直接扱った出典は1件のみで、採用基準（民間2件）を満たしません。

## パック候補

PRD §4.1 の契約：`correction_rules` は既存の7フィールドを使い、注入文字列は日本語で書きます。例文はすべて新たに作成しました。`reason` には日本語の規範のみを書き、出身への言及は入れません。

### 第1次マージ推奨 (+3 rules, +1 note)

```json
{"id":"rep-sasete-itadaku","type":"replace","pattern":"〜させていただきました／〜させていただきます（相手の許可も恩恵もない自分の行為）","replacement":"〜しました／〜いたします","reason":"許可を受けて恩恵を得る行為以外に使うと冗長になる。経歴は言い切る。","example_before":"2018年に大学を卒業させていただき、物流会社で在庫管理を担当させていただきました。","example_after":"2018年に大学を卒業し、物流会社で在庫管理を担当しました。"}
```
根拠 [c2-01][c2-02][c2-18] · 信頼度 high（規範）。転移根拠なし。

```json
{"id":"rep-uchi-keishou","type":"replace","pattern":"勤務先の上司を面接官に対して「〇〇部長」「おっしゃる」などで立てる","replacement":"「上司の〇〇」「部長の〇〇」＋普通の動詞（言う・申す）","reason":"社外の相手に対しては自分側の人物を立てない。名前＋役職はウチ扱いにならない。","example_before":"現職では、鈴木部長がいつもおっしゃっているとおり、週次で数字を報告しています。","example_after":"現職では、上司の鈴木の方針で、週次で数字を報告しています。"}
```
根拠 [c2-04][c2-05] 規範 + [c2-06][c2-07][c2-08] 転移 · 信頼度 medium（現職の範囲は high、前職への拡張は未確認）。`T4-interview.md` の `t4-keigo-self-side` とのマージを検討すること。

```json
{"id":"rep-onsha-spoken","type":"replace","pattern":"貴社（面接など話すとき）／御社様","replacement":"御社","reason":"貴社は書き言葉。話すときは御社。敬称は重ねない。","example_before":"貴社の在庫管理システムに関心があります。","example_after":"御社の在庫管理システムに関心があります。"}
```
根拠 [c2-10][c2-11] · 信頼度 medium。転移根拠なし。

`culture_notes` 候補（日本語1文）：
- `面接で勤務先の上司や同僚に触れるときは、面接官に対して自分側の人物として扱い、名前に役職や尊敬語を付けずに話す。` 根拠 [c2-04][c2-05] · medium。出身に関するノートではなく、日本語の規範ノートです。

注入量：上記規則3件の JSON + ノート1件 = 832字（JSON 文字列長基準の実測）で、1,000字の予算内です。

### 第2次候補

```json
{"id":"rep-yakushoku-sama","type":"replace","pattern":"役職名＋様（部長様・社長様）","replacement":"〇〇部長／部長の〇〇様","reason":"役職名がすでに敬称。様を重ねない。","example_before":"本日は人事部長様からもご説明いただき、ありがとうございました。","example_after":"本日は人事部長の〇〇様からもご説明いただき、ありがとうございました。"}
```
根拠 [c2-13][c2-14] · medium。指針の二重敬語の定義を根拠にはしません [c2-03]。

```json
{"id":"rep-daijoubu-kahi","type":"replace","pattern":"可否・要否を聞かれて「大丈夫です」だけで答える","replacement":"「はい、可能です」／「いいえ、必要ありません」＋条件","reason":"承諾にも断りにも聞こえ、答えが伝わらない。","example_before":"（転勤は可能ですか）大丈夫です。","example_after":"はい、可能です。勤務地は全国どこでも問題ありません。"}
```
根拠 [c2-15][c2-16] · medium。**置換テスト：出身を入れ替えても真 → 共通規則。** C2 転移規則としては表記しません。

```json
{"id":"rep-yohi","type":"replace","pattern":"〜与否（話すとき）","replacement":"〜かどうか","reason":"漢語を直訳した形で、話し言葉では「〜かどうか」が自然。","example_before":"導入与否は、テスト結果を見て判断しました。","example_after":"導入するかどうかは、テスト結果を見て判断しました。"}
```
根拠 [c2-09] · low~medium（学術1件、標本2名）。`reason` の「話し言葉では自然」の部分は出典の直接の記述ではなく、誤用分類から推論したものです。

### doc_only（パック候補ではない）
- **頑張ります の多用**：出典1件 [c2-17]。既存の `str-number`（根拠は数字・基準1つ）と趣旨が重なります。2つ目の出典を確保するまでは保留します。
- **助詞の転移（〜を会う、〜を乗る、〜がなる）**：カテゴリーの根拠のみです [c2-09]。個別の形の出典は開けませんでした。初級の誤りであるため、中途ペルソナ（N1・N2）との関連性も低いです。
- **現職を弊社と呼ばない**：単一出典 [c2-12]。指針【24】の「弊社の部長」（会社員が取引先に話す場面）とは場面が異なるため、衝突はしません。ただし人による確認が必要です。

## 未確認

- **前職の上司のウチ扱い**：面接で前職の上司のことを話すときにウチとして扱うことが規範かどうかは確認できませんでした。指針は現職の場面のみを扱っています。公的出典は未確認です。
- **韓国語側の転移機制**：〜드리겠습니다 → させていただく の多用、귀사（口語での使用）→ 貴社、부장님 → 部長様、괜찮습니다 → 大丈夫です、열심히 하겠습니다 → 頑張ります。5つすべてについて出典を見つけられませんでした。**これらの規則を「韓国語干渉」と説明してはいけません。**
- **漢字語 false friend の新規語**（例：進行、工夫、勉強 など）：語ごとの出典を開けませんでした。崔 1991（教科書の字音漢語 1882語のうち約6%が意味の違い）は検索の要約でのみ確認し、本文は未確認です。
- **「〜している中です」（하는 중：〜しているところ）の転移**：出典なし。
- **国語に関する世論調査における「大丈夫です」の設問の有無**：確認できませんでした。
- **言語研究 95号（1989）大会発表要旨（日韓の第三者敬語比較）**：J-STAGE の PDF がスキャン画像のため読めませんでした。引用しません。
