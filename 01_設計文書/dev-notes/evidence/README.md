## 補足

- Workflow スクリプトは Claude Code の Workflow 機能で実行したもので、`agent()`、`parallel()`、`phase()` などはその実行環境が提供する関数です。単体の Node.js では動きません。
- `form-fill.js` と `yt-upload.js` は、Claude Code のブラウザ操作の実行環境（`listBrowserTabs`、`openTab`、`snapshot` など）で実行したものです。
- 本番アプリの URL（`https://mensetsu-coach-ten.vercel.app`）は、リポジトリの README に記載済みの公開ドメインのため伏せていません。
