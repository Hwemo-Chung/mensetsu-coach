## 0. 이번 패스에서 바뀐 결론

1. **출신별(영미권·한국·중국·동남아·인도) 면접 행동 차이를 뒷받침하는 공적 근거를 찾지 못했습니다.**
   따라서 C1~C5를 5개 문서로 나누지 않고 `ORIGIN-NOTES.md` 1개로 통합할 예정입니다(미작성). 근거 없는 20칸을 문서로 채우는 것은 리서치가 아니라 환각입니다.
2. **メンパス는 실재합니다.** App Store에서 확인했습니다. 기존 시장 분석 문서(비공개)의 "실재 확인 불가"는 철회합니다.
3. **6.1%는 이직률이 아니라 "이직 희망" 응답입니다.** 技人国은 5.5%입니다. 모집단도 전수 행정집계가 아니라 「2025년 외국인 고용 실태조사」 표본(5인 이상 사업장, 노동자 14,248명)입니다.
4. **JASSO 38.8%의 분모는 64,331명이 아닙니다.** 진로 불명 1,493명을 제외한 62,838명이 분모입니다. 전체 졸업자 대비로는 37.9%입니다.
5. **`claude-opus-5-5`는 유효한 모델 ID입니다.** ZDR(Zero Data Retention)도 신청 가능한 조직에서 사용할 수 있습니다. 단, ZDR은 기본값이 아니라 별도 신청입니다.

- **공적 1차 자료 우선**: 厚生労働省, 出入国在留管理庁, JASSO, 文化庁, ハローワーク, 内閣官房.

- **모든 수치에 모집단·정의·시점·출처·신뢰도**를 붙입니다.
- **추정은 추정이라고 표시**합니다. `[Medium]`은 2차 자료·합리적 추론, `[Low]`는 근거 있는 가설, `[Unknown]`은 확인 불가.
- **접근일**: 별도 표기가 없으면 2026-11-02.

## 4. 이번 패스에서 채택하지 않은 것

- **출신별 면접 행동 규칙**: 공적 통계 없음. 민간 블로그·Reddit 사례는 대표성 없음.
- **年収交渉·スカウト 대응·一次/二次/最終 평가축**: 일본 공적 자료에서 일반화 가능한 규범을 찾지 못함.
- **英文レジュメ → 일본식 변환**: 공적 규범 없음.
- **STAR/PREP가 일본 표준이라는 주장**: 글로벌 민간 도구의 프레임. 일본 공적 자료는 4문형을 말하지 않음.
- **内定辞退 예절(며칠 전까지 연락 등)**: 공적 자료 없음.
- **소개 수수료 30~35%가 법정 요율이라는 주장**: 민간 관행. 법정 요율 아님.
- **"일본 서비스는 모국어 피드백이 없다"**: 부재 증명 불가. "확인한 범위에서"로만 표기.

## 5. 제품 반영 제안(요약)

- `T3`·`T4`의 공적 규범은 **규칙 후보**로 바로 쓸 수 있습니다. 단, `packs/jp.json`은 사람이 승인한 뒤 별도 작업.
- `T1`·`T2`는 면접 규칙이 아니라 **전 과정 안내(process note)** 로 분리해야 합니다.
- 출신별 규칙은 **0건**입니다. 마케팅에서 "국적별 맞춤"을 쓰려면 1차 인터뷰 연구가 먼저입니다.

## 7. RESEARCH-PRD와의 차이

`RESEARCH-PRD.md`는 9개 조사 문서 + `jp-draft-v2.json` + 38개 에이전트를 계획했습니다. 이번 패스는 다음 이유로 축소했습니다.

- 출신 5개 문서는 근거가 없어 1개로 통합했습니다. 문서 수를 채우기 위해 내용을 만들지 않았습니다.
- (첫 패스 당시) `jp-draft-v2.json`은 만들지 않았습니다. **이후 R1 패스(2026-11-02)에서 R1 후보만으로 초안을 만들었습니다** — §3 색인과 `SUMMARY.md` 참고. `T3`·`T4` 후보는 그 초안에 들어 있지 않습니다.
- 38개 에이전트 대신 공적 1차 자료를 직접 열람했습니다. 비용은 줄이고 검증 가능성은 높였습니다.
