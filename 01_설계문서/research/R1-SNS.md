# R1-SNS — 外国人の日本での面接失敗事例に繰り返し現れるパターン（SNS・コミュニティ、内部リサーチ）

- **異なる投稿者2名以上**が報告したパターンのみを記します。同じスレッド内の複数のコメントは1件と数えます。すべての文は新たに書き起こしました。
- 信頼度の上限は `medium` です。自己報告の逸話であり、代表性がないためです。根拠の一方が商業コーチング・エージェンシーのブログ（マーケティング目的）であれば `low` に下げます。このユニットに `high` はありません。
- 出身を理由とした規則は作りません。すべてのパターンに置換テスト（出身を入れ替えても真か）を適用しました。すべて通過したため、**共通規則**として扱います。

## 要約

1. **繰り返し現れるパターンを9つ確認しました。** そのうち4つは既存の R1 候補を**現場の事例で裏付ける**ものです。① 志望動機が「日本が好きだから」にとどまる → `R1-T4.md` の `str-why-japan-axes` ② N1 があっても面接の日本語で減点される → `R1-T4.md` の `str-japanese-evidence` ③ 希望年収の不一致 → `R1-T2b.md` の `str-salary-range` ④ 在留残存期間への懸念 → `R1-T4.md` の `str-visa-facts`、`R1-T5.md`。新しい規則を別途作らず、既存候補の根拠を補強します。
2. **新たに出てきたのは3つです。** 最終面接では能力よりも入社意欲と会社の方向性への理解を見るという報告が繰り返されています。[R1SNS-04] 資格・スコアを並べるだけでは根拠になりません。[R1SNS-06] 企業は不合格の理由をほとんど教えてくれません。[R1SNS-05]
3. **製品のポジショニングにとって最も重要な事実は [R1SNS-05] です。** 会社がしてくれない振り返りをコーチが代わりに行うべきだという根拠になるためです（解釈）。
4. **声の大きさ・自信といった伝達要素も繰り返し現れます。** [R1SNS-07] テキストのコーチではこれを測定できないため、doc_only とします。音声機能（ストレッチ目標）で改めて検討します。
5. **「強い自己主張が組織への適合性の懸念として受け取られる」という報告は、出身のフレームを帯びて入ってきます。** [R1SNS-08] そのため行動基準に書き換え、doc_only、low とします。注入テキストでは出身に言及しません。
6. **パック候補は少数です。** culture_notes 新規2件（注入92字）と failure_pattern 9件です。残りは既存候補を補強する doc_only です。他のユニットの規模（+3/+5）に合わせるために埋めることはしていません。

## 確認された事実（繰り返し現れるパターン）

形式：状況 → 原因（報告者・観察者が挙げた原因。因果は検証していない）→ 教訓 → コーチの発話（ko / ja、私たちが新たに書いた文）。

### SNS-P1. 志望動機と企業研究が浅くて落ちる（既存 `str-why-japan-axes` の補強）
- 状況：書類は通過するものの、面接、特に後半の段階で落ちます。同じ応募書類を複数の会社に使い回しているケースが多くあります。[R1SNS-01]
- 原因：志望動機が「日本の文化・日本語が好き」という個人の好みにとどまっています。なぜこの会社なのかを、会社の事業と結びつけて話せていません。[R1SNS-01]
- 教訓：動機は、きっかけ（過去）、日本でやりたいこと（将来）、この会社でなければならない理由の3段で話します。この構造は `R1-T4.md` の [R1T4-20] の構造と同じです。
- コーチの発話：ko 「'일본이 좋아서'는 취향입니다. 이 회사 사업과 이어지는 이유를 한 문장 더하세요.」 / ja 「「日本が好き」は動機ではなく好みです。御社の事業につながる理由を一文足しましょう。」

### SNS-P2. JLPT N1 があっても面接の日本語で減点される（既存 `str-japanese-evidence` の補強）
- 状況：N1 保有者が最終段階まで進んで落ちる、あるいは「日本語が不自然だ」という印象を残します。[R1SNS-02]
- 原因：級は指標にすぎず、面接は実際の会話で評価されるという証言が繰り返されています。結論から話す構成、場面に合った敬語、自然な表現が別途求められます。[R1SNS-02] JLPT に会話試験がないという公的な事実は `R1-T4.md` の [R1T4-24] にあります。
- 教訓：級の代わりに、日本語で働いた場面と結論から話す回答で証明します。
- コーチの発話：ko 「N1은 출발점입니다. 이 답을 결론 한 문장부터 다시 말해 보세요.」 / ja 「N1は出発点です。この答えを、結論の一文から言い直してみましょう。」

### SNS-P3. 希望年収がレンジとずれると、それだけで終わる（既存 `str-salary-range` の補強）
- 状況：キャリアチェンジでありながら高い金額を提示して最終で落ちます。逆に、現年収が求人のレンジよりかなり高いという理由で、本人がレンジを受け入れても選考が中止されます。[R1SNS-03]
- 原因：企業はレンジ外の候補者を「合わせられない」または「長く定着しないだろう」と判断するという報告があります。[R1SNS-03]
- 教訓：現年収を根拠に、求人レンジ内の幅で答えます。現年収がレンジより高い場合は、受け入れる理由（職務・成長・生活）を先に話します（解釈）。**「現年収が高すぎて落ちる」という方向は、R1-T2b にない新しい情報です。**
- コーチの発話：ko 「현 연봉이 이 레인지보다 높다면, 이 금액을 받아들이는 이유를 먼저 말하세요.」 / ja 「現年収がこの求人の幅より高いなら、その金額を受け入れる理由を先に伝えましょう。」

### SNS-P4. 最終面接は能力の確認ではなく、入社意欲と方向性への理解を見る場である（新規）
- 状況：前の段階はすべて通過したのに、役員面接で落ちます。本人は雰囲気がよかったと感じています。[R1SNS-04]
- 原因：最終では、入社意欲、長く働く意向、会社が今後向かおうとする方向への理解を見るという報告が繰り返されています。意欲が感じられなければ記憶に残らないという面接官側の観察もあります。[R1SNS-04]
- 教訓：最終の前には、企業の最近の発表・中期の方向性を確認します。入社後にやりたいことをその方向に結びつけて、一文で準備します。逆質問の1つはその方向について尋ねます。
- コーチの発話：ko 「최종면접입니다. 이 회사가 앞으로 가려는 방향과, 거기서 당신이 맡을 일을 한 문장으로 이어 주세요.」 / ja 「最終面接です。御社がこれから向かう方向と、そこで自分が担う仕事を一文でつないでください。」

### SNS-P5. 不合格の理由を教えてもらえず、同じ失敗を繰り返す（新規、製品ポジショニング）
- 状況：結果は定型文でしか届きません。応募者は理由がわからないまま、同じ書類・同じ回答で応募を続けます。[R1SNS-05]
- 原因：具体的なフィードバックを出さないのが慣行だという面接官側の説明があります。紛争の火種を避けるためだとされています。[R1SNS-05]
- 教訓：面接の直後に、詰まった質問と実際にした回答を書き留めておき、次の練習問題として使います。
- コーチの発話：ko 「회사는 이유를 알려주지 않습니다. 오늘 막혔던 질문 하나와 그때 한 답을 적어 주세요. 다음 연습에 쓰겠습니다.」 / ja 「企業は理由を教えてくれません。今日詰まった質問と、そのときの答えを書いてください。次の練習に使います。」

### SNS-P6. 資格・スコアの羅列は根拠にならない（新規）
- 状況：学位・級・語学スコア・インターン回数を前面に出したのに、1~2次で落ちます。[R1SNS-06]
- 原因：面接官はリストではなく、その経験で何を判断し、なぜそうしたのかを尋ねます。自己分析がなければ、深掘りの質問で回答が崩れます。[R1SNS-06]
- 教訓：資格1つに判断の場面1つを添えます。定型の質問は練習しつつ、暗記した文ではなく4文型の構造（復唱→結論→基準·数字→選択肢）を自分の言葉で埋めます。「模範解答を練習せよ」という助言と「暗記した答えは崩れる」という助言が併せて報告されていますが、この構造で両者を両立できます（解釈）。
- コーチの発話：ko 「자격은 그대로 두고, 그 경험에서 당신이 내린 판단 하나를 덧붙이세요.」 / ja 「資格はそのままで、その経験で自分が下した判断を一つ添えましょう。」

### SNS-P7. 声・自信の不足が「入社後に大丈夫だろうか」と受け取られる（doc_only、伝達要素）
- 状況：技術評価はよかったのに、採用責任者が落とします。[R1SNS-07]
- 原因：小さな声、硬い表情、曖昧な答えが入社後の不安として解釈されるという面接官側の観察が2件あります。緊張そのものは減点ではないとされています。[R1SNS-07]
- 教訓：テキストで練習できるのは、最初の一文を短く区切って話すことだけです。音量・表情は音声・映像機能の領域です。
- コーチの発話：ko 「첫 문장을 짧게 끊어, 또박또박 말하는 연습부터 하세요.」 / ja 「最初の一文を短く区切って、はっきり言う練習から始めましょう。」

### SNS-P8. 強い自己主張・変革のアピールが組織への適合性の懸念として受け取られる（doc_only、low、出身フレームを除去）
- 状況：独自の判断、リーダーシップ、「新しい風を入れる」を前面に出した回答がよい評価を得られません。[R1SNS-08]
- 原因：報告者たちは出身文化を原因に挙げました。本文書は出身ではなく**行動**として記録します。慎重すぎると推進力がないように見えるという、逆方向の報告も併せてあります。[R1SNS-08]
- 置換テスト：日本人の候補者が同じ回答をしても同じ懸念を招く → 出身の規則ではなく共通規則。欠損テスト：候補者の欠陥を含意せず、回答の配置の問題として扱う → 通過。
- 教訓：変化の提案は「まず現場のやり方を理解したうえで、この経験でこのように貢献する」の順で話します（設計）。
- コーチの発話：ko 「바꾸겠다는 말 앞에, 먼저 배우겠다는 한 문장을 두세요.」 / ja 「変えたいと言う前に、まず学ぶという一文を置きましょう。」

### SNS-P9. 在留残存期間・資格変更の負担が選考で懸念される（既存 `str-visa-facts`・R1-T5 の補強）
- 状況：在留の残存期間が短い状態で転職活動をすると、面接まで進んでもビザの話で行き詰まると報告されています。求人で「就労制限のない資格の保有者」を条件にする事例も報告されています。[R1SNS-09]
- 原因：企業が資格変更手続きの負担と期間を懸念しているという報告者たちの解釈があります。必要な残存期間の数値は単一出典のため未確認です。[R1SNS-09]
- 教訓：資格名・期限・転職時に本人が行う手続き（14日 届出）を、事実として短く先に話します。公的根拠は `R1-T5.md` の [R1T5-11]、`R1-T4.md` の [R1T4-07] にあります。求人の国籍条件には指針上の留意事項があります。[R1T4-16]
- コーチの発話：ko 「비자는 '괜찮다' 대신 자격명·기한·이직 시 수속을 한 문장으로 말하세요.」 / ja 「ビザは「大丈夫」ではなく、資格名・期限・転職時の手続きを一文で伝えましょう。」
