## 2. 段階別の評価観点（一次/二次/最終）
- 面接官の構成は会社ごとに異なる。パターンA: 一次 人事 → 二次 現場 → 最終 役員 / パターンB: 一次 現場 → 二次 人事 → 最終 役員。2回選考なら二次が最終 (S3)。
- 基本的な質問は段階が上がってもほぼ同じで、**観点と深掘りの深さ**が変わる (S3, S9)。
- 一次: 人事担当なら社風への適合・定着性（転職理由、志望動機）、現場なら経験・スキルの確認 (S3, S5)。基本的なコミュニケーション・第一印象・意欲 [未確認: S5の再閲覧では確認できず]。
- 二次 (S9): 1~3名、約1時間。一次の内容を引き継ぎ、同じテーマを深掘りする（例: 転職理由の再追及）。職務適合、チーム・文化適合、定着・意欲、企業/職務理解。
- 最終 (S3, S5, S6): 役員/部門長/代表。長期的な適合（性格・スキル）、入社意欲の確認、経営方針とキャリアビジョンの一致、「なぜこの会社か」の具体性、他社選考状況・第一志望かどうか、勤務条件（残業など）。形式的な手続きではなく、前の回答が再追及されることもある。
- 段階横断: **一貫性**（転職理由・志望動機・自己PRが面接官間で共有され照合される） (S3, S6, S9)。

## 3. 公開調査のシグナル
- doda 採用担当者 n=2,000 (2025-09): 評価項目の上位 = 受け答えの仕方 51.1%、誠実さ・素直さ 47.4%、経験 44.0%。単一の最重要項目 1位 受け答えの仕方 9.9% / 2位 誠実さ・素直さ 9.0% / 3位 志望動機 7.3%（Sv1, 2026-11-02 再確認）。
- 識学 n=300 (2022): 中途採用で重視 = コミュニケーション能力 76.1%、協調性 55.2%、誠実さ・信頼 51.7% (Sv2)。
- HR総研 n=511（2012、古い）: 経歴・スキルが最上位、次いで人柄・熱意 (Sv3) [Low: 年代が古い]。
- 未閲覧（スニペットのみ）: 学情 20代中途調査「人柄・社風との相性 89.3%」、マイナビ 中途採用状況調査2023 → 原文確認までは引用禁止。
- 結論 [Medium]: スキルと同程度に「受け答えの仕方・誠実さ・コミュニケーション」が上位 → コーチのフィードバックには内容（structure）だけでなく伝え方の軸も必要。

## 5. 提案（packの修正はこの作業の範囲外）
