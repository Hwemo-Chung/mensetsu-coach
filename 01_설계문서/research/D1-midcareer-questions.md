## 2. 단계별 평가 관점 (一次/二次/最終)
- 면접관 구성은 회사마다 다름. 패턴 A: 1차 인사 → 2차 현업 → 최종 임원 / 패턴 B: 1차 현업 → 2차 인사 → 최종 임원. 2회 전형이면 2차가 최종 (S3).
- 기본 질문은 단계가 올라가도 거의 동일하고, **관점과 파고드는 깊이**가 달라짐 (S3, S9).
- 一次: 인사 담당이면 사풍 적합·정착성(전직 이유, 지원 동기), 현업이면 경험·스킬 확인 (S3, S5). 기본 소통·첫인상·의욕 [未確認: S5 재열람에서 확인되지 않음].
- 二次 (S9): 1~3명, 약 1시간. 1차 내용을 이어받아 같은 주제를 깊이(예: 이직 이유 재추궁). 직무 적합, 팀·문화 적합, 정착·의욕, 기업/직무 이해.
- 最終 (S3, S5, S6): 임원/부문장/대표. 장기 적합(성격·스킬), 입사 의욕 확인, 경영 방향과 커리어 비전의 일치, "왜 이 회사인가"의 구체성, 타사 선고 상황·1순위 여부, 근무 조건(잔업 등). 형식적 절차가 아니며 앞 답변이 재추궁될 수 있음.
- 단계 횡단: **일관성** (이직 이유·지원 동기·자기PR이 면접관 간 공유되어 대조됨) (S3, S6, S9).

## 3. 공개 조사 신호
- doda 採用担当者 n=2,000 (2025-09): 평가 항목 상위 = 受け答えの仕方 51.1%, 誠実さ・素直さ 47.4%, 経験 44.0%. 단일 최중요 1위 受け答えの仕方 9.9% / 2위 誠実さ・素直さ 9.0% / 3위 志望動機 7.3% (Sv1, 2026-11-02 재확인).
- 識学 n=300 (2022): 중도채용 중시 = コミュニケーション能力 76.1%, 協調性 55.2%, 誠実さ・信頼 51.7% (Sv2).
- HR総研 n=511 (2012, 오래됨): 경력·스킬 최상위, 다음 인품·열의 (Sv3) [Low: 연식].
- 미열람(스니펫만): 学情 20대 중도 조사 "人柄・社風との相性 89.3%", マイナビ 中途採用状況調査2023 → 원문 확인 전까지 인용 금지.
- 결론 [Medium]: 스킬만큼 "대답하는 방식·성실함·소통"이 상위 → 코치 피드백에 내용(structure)뿐 아니라 전달 방식 축 필요.

## 5. 제안 (pack 수정은 이 작업 범위 밖)
1. stages에 二次面接 추가, 단계별 평가 관점(위 §2)을 culture_notes 데이터로.
2. categories를 経歴・志望動機 → {自己紹介, 転職理由, 志望動機, 実績・経験, 強み弱み, キャリアプラン, 条件・入社時期, 逆質問, マネジメント, 技術}로 세분.
3. 코치 평가축에 "일관성(면접관 간)"과 "전향적 이직 이유" 추가.

## 6. 취득하지 않음 / 한계
- リクナビNEXT, エン転職, マイナビ転職(본체), ビズリーチ(본체): 검색에서 일반 면접 질문 기사가 나오지 않아 미수집. 차단 우회 시도 없음.
- 口コミ・体験談 사이트(OneCareer 등): 개인 사례이므로 取得しない.
- robots.txt 확인: r-agent(일부 쿼리 경로만 Disallow), mynavi-agent, tenshoku.mynavi(/a/만), directscout(전체 허용), axxis(wp-admin만), allabout(일부), doda·hrmos(robots 응답 없음). 이용약관 개별 확인은 하지 않음 → 기사 본문은 재서술만, 인용 없음.
- 정부 페이지는 이번에 사용하지 않음 (terms_url 해당 없음).
- WebFetch는 요약 모델 경유. 검증 단계(2026-11-02)에서 Sv1·Sv2 수치, S5 호스트, S9(면접관 1~3명·약 60분) 재확인 완료. 그 외 세부는 [Medium].
