# KR-K2: 일본어 화자의 한국어 면접 발화 간섭 패턴 (한국 기업 면접용 신규 팩 후보)

작성일 2026-11-02. 용도: 일본인 구직자가 한국 기업을 한국어로 면접볼 때 쓰는 신규 국가 팩의 correction_rules 후보. 간섭 패턴은 언어 전이 현상으로만 기술하며 특정 집단의 특성으로 일반화하지 않는다.

## 요약

- 확인된 공개 근거는 대부분 서지 초록 수준이다. 조사 오용과 경어법 오류 두 영역만 일본어권 학습자 대상 직접 근거가 있다. 합쇼체·해요체는 부분 근거다.
- 한자어 동형이의어, 〜と思います 직역, 〜させていただく 직역, 「よろしくお願いします」 직역은 일본인 학습자를 직접 다룬 연구를 이번 검색에서 찾지 못했다(미확인).
- 공공누리 제1유형으로 확인된 출처가 없다. 모든 출처는 kind "private"이므로 사실만 요약했고, 예문은 전부 직접 작성했다.
- 따라서 팩 후보 7개 중 R1·R2만 근거 2건 이상(medium)이고, R3~R7은 low로 "보류" 상태다. 팩 반영 전 원어민 검수 또는 추가 출처가 필요하다.

## 확인된 사실

- 김정은(2004)은 일본어권 학습자의 한국어 조사 10개 오용을 숙달도별로 분석했다. [K2-01]
- 같은 연구는 초급 이후에도 조사 반복 학습이 필요하고 일본어권 학습자에게서 모어 간섭이 더 뚜렷하다고 제시한다. [K2-02]
- 일본인 학습자 작문의 주격조사 이/가 오류를 다룬 연구는 이/가와 은/는의 혼동이 고급 단계에서도 나타난다고 보고한다(초록 요약만 확인). [K2-03]
- 2023년 연구는 일본인 학습자의 경어 오류 원인으로 모어 간섭, 활용 이해 부족, 부적절한 어휘 선택을 들고 -(으)시 과용을 지적한다. [K2-04]
- 이화여대 학위논문은 일본인·중국인 고급 학습자의 합쇼체·해요체 전략 차이를 문화적 요인과 연결해 비교한다(초록 요약만 확인). [K2-05]
- 중앙대 연구는 중급 학습자가 발표 담화에서 합쇼체와 해요체를 오가며 부적절한 상대 높임을 자주 보인다고 보고하나, 일본어권에 한정되지 않는다. [K2-06]
- 이화여대 연구는 일본어권 중급과 고급 학습자의 공손성 실현에 유의한 차이가 없었다고 보고한다. [K2-07]
- 고급 일본인 학습자 작문 분석은 모어 간섭을 가장 중요한 오용 요인으로 보고한다(원문 열람 실패, 검색 요약 기준). [K2-08]
- 한일 한자음 대응을 이용한 한자어휘 교육 실험(학습자 10명)은 존재하나 동형이의어 오용 분석은 아니다. [K2-09]
- 일본어 추량 표현과 한국어 '것 같다'의 대응을 다룬 대조 연구가 있으나 한국인의 일본어 학습 방향이다. [K2-10]
- 국립국어원 오류 말뭉치의 일본인 자료 약 30만 어절을 분석한 피동 오류 연구가 있다. [K2-11]
- 국립국어원 학습자 말뭉치 2차 사업이 일본어권을 포함해 확장될 예정이라는 언론 보도가 있다. [K2-12]

## 팩 후보

필드: id, type, pattern, replacement(한국어), reason(한국어), example_before, example_after. 예문은 전부 직접 작성. 주입 텍스트는 한국어, 일본어 설명은 UI 노트용이며 팩에는 넣지 않는다.

일본어 설명 노트(md 전용, 팩 비주입):
- R1 kr-topic-ga: 韓国語の「은/는」は主題、「이/가」は新情報の主語を示す。日本語の「は／が」と似ているため、初出の出来事に「は」を当てる転移が起きやすい。
- R2 kr-register-mix: 面接では「합쇼체」で統一する。「해요체」が混ざると場にそぐわない印象になる。
- R3 kr-omoimasu: 「〜と思います」を逐語訳し「~라고 생각합니다」を毎文に付けると、断定を避けているように聞こえる。根拠のある主張は言い切る。
- R4 kr-kanji-benkyo: 漢字語は音が対応しても意味範囲がずれる。「공부」は学習行為を指す。
- R5 kr-sasete: 「〜させていただく」の直訳は韓国語では不自然。「-겠습니다」を使う。
- R6 kr-yoroshiku: 「よろしくお願いします」は万能の挨拶だが、韓国語では場面別に言い分ける。
- R7 kr-shi-overuse: 「-(으)시」を自分の動作に付けない。

## 미확인

- 한자어 동형이의어(勉強 등)가 일본인 한국어 학습자 발화에서 실제로 오용되는 빈도·양상: 직접 연구 미발견. [미확인]
- 〜と思います 직역으로 '-라고 생각합니다'·'것 같습니다'가 과잉 사용되는 현상: 직접 연구 미발견. 대조 연구(K2-10)만 있음. [미확인]
- 〜させていただく 직역, 「よろしくお願いします」 직역의 한국어 대응 오류: 직접 연구 미발견. [미확인]
- 일본인 학습자의 내집단 낮춤 경향과 인사말·부탁 기능 구분 어려움을 다룬 연구를 검색 요약에서 보았으나 개별 URL을 확정하지 못해 근거에서 제외했다. [미확인]
- 공공누리 제1유형 출처: 국립국어원 학습자 말뭉치의 이용 조건은 이번 검색에서 확인하지 못했다. 제1유형 확인 전에는 말뭉치 원문 문장을 쓰지 않는다. [미확인]
- 검색 결과 요약 중 K2-03, K2-05, K2-07, K2-08, K2-10은 초록 페이지 본문을 직접 열람하지 못했다. 팩 반영 전 원문 확인 필요.
- 원어민 검수: 팩 예문 7개는 전부 한국어 모어 화자 검수를 거치지 않았다. 한국 기업 면접 환경에서의 합쇼체 규범은 별도 근거 없이 일반 관행으로 가정했다. [미확인]
