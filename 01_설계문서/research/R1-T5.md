# R1-T5 在留資格・就労許可（転職時）

作成 2026-11-02。上位: `../RESEARCH-PRD.md` §2.1 T5 行。先行文書 `R1-T4.md`(R1T4-07・14・15・18・19)を**拡張**します。T4 が検証した事実は id でのみ引用し、再閲覧はしていません。
**法律相談ではありません。** コーチが面接回答を扱う際に知っておくべき前提のみを整理します。個別事案の判断は地方出入国在留管理官署・行政書士・弁護士の役割です。

## 要約

1. **技人国の要件は3層です。** 法律（活動の定義、別表） → 省令（学歴・実務経験・報酬） → 行政ガイドライン（専攻と業務の関連性判断、単純・反復業務の除外）。大学卒業者の関連性は「柔軟に」判断され、専修学校は「相当程度」が必要です。[R1T5-01][R1T5-03][R1T5-06][R1T5-07]
2. **転職時の本人の義務は14日以内の届出1つです。** 同じ技人国の活動を続けるのであれば変更許可は不要です。届出はオンライン可、証明資料不要。未届出は罰金の対象となり、次回の変更審査で届出の履行状況が考慮されます。[R1T4-18][R1T5-11][R1T5-12][R1T5-13][R1T5-15][R1T5-08]
3. **高度専門職1号は例外です。** 所属機関の変更にも在留資格変更許可申請が必要です。届出だけでは済まないため、入社可能時期の回答が変わります。[R1T5-26]
4. **就労資格証明書は任意です。** 本人の申請に基づくものであり、活動が明らかであれば不提示を理由とする不利益取扱いは法律で禁止されています。用途は「新しい業務が現在の資格で可能かどうかの確認」です。民間解説にある「更新の簡素化」効果は一次資料で確認できませんでした。[R1T4-19][R1T5-17][R1T5-18][R1T5-30]
5. **退職後3か月の空白は取消事由になり得ます（裁量、正当な理由がある場合を除く）。** 面接で前職の退職日を尋ねる根拠はこれです。[R1T5-14][R1T5-29]
6. **2026-04-15 新設**: カテゴリー3・4の企業で言語による対人業務（翻訳・通訳等）に主に従事する場合、CEFR B2 の証明（N2 等で充足とみなされる）が必要です。転職によってそのような業務に移る場合は更新時に提出します。韓国人候補者の通訳・翻訳職への転換に直接関係します。[R1T5-09][R1T5-10]
7. **就労制限のない資格**は別表第二の4種（永住者・日本人の配偶者等・永住者の配偶者等・定住者）です。入管法19条の活動制限は別表第一にのみ適用されます。[R1T5-20][R1T5-21][R1T4-15]

## 確認された事実

### 1. 技人国の要件（学歴・業務関連性）

- 技人国の活動は、本邦の機関との契約に基づく自然科学・人文科学分野の技術・知識を要する業務、または外国の文化に基盤を有する思考・感受性を必要とする業務です。例として機械工学の技術者、通訳、デザイナー、語学教師、マーケティング業務が挙げられています。[R1T5-01]
- 在留期間は5年・3年・1年・3か月のいずれかです。[R1T5-02]
- 自然科学・人文科学分野の業務には、①関連科目を専攻した大学卒業（同等以上を含む） ②関連科目を専攻した本邦の専修学校修了（告示の要件） ③10年以上の実務経験、のいずれかが必要です。告示の情報処理試験合格・資格保有者は例外です。[R1T5-03]
- 外国の文化に基盤を有する業務（翻訳・通訳・語学指導・広報・宣伝・海外取引・デザイン・商品開発等）には、関連業務で3年以上の実務経験が必要です。大学卒業者の翻訳・通訳・語学指導は例外です。[R1T5-04]
- 報酬は日本人と同等額以上である必要があります。実費弁償の性格を持つ手当は報酬に含めません。[R1T5-05]
- 専攻と業務の関連性: 大学（海外を含む）・高専は柔軟に、専修学校は原則として相当程度の関連性が必要です。専修学校修了者も、関連業務に3年程度従事した後は柔軟に判断されます。[R1T5-06]
- 活動は在留期間全体で判断します。該当業務がごく一部で、残りが単純・反復業務であれば非該当です。日本人と同様の入社初期の研修は例外として扱われます。[R1T5-07]
- 2026-04-15 以降のカテゴリー3・4: 代表者の申告書 +（言語による対人業務の場合） CEFR B2 の証明。JLPT N2 以上、BJT 400点以上、日本の大学卒業等は B2 とみなされます。[R1T5-09]
- 転職・業務変更により言語業務に主に従事することになった場合は、更新時に B2 の資料を提出します。同じ業務を継続する場合は原則として不要です。[R1T5-10]

### 2. 転職時の手続き

- 19条の16の届出事由は資格群ごとに異なります。技人国・高度専門職1号イロ・研究・技能等（第2号）は契約の終了・新たな契約の締結、経営・管理・企業内転勤等（第1号）は活動機関からの離脱・移籍が事由であり、いずれも14日以内です。永住者は対象外です。[R1T5-11]
- 届出の主体は本人で、オンラインで可能です（T4 で確認）。[R1T4-18]
- 電子届出システムは24時間受付、証明資料不要。窓口・郵送も可能です。契約の終了・新たな契約を一度に提出できる様式（参考様式1の7）があります。[R1T5-12]
- 未届出は20万円以下の罰金、虚偽の届出は1年以下の拘禁刑または20万円以下の罰金の対象です。[R1T5-13]
- 技人国への変更許可の審査では、届出義務の履行状況が考慮されます。[R1T5-08]
- 同じ在留資格の活動を続ける場合、変更許可は不要ですが本人の届出は必要です。満了日が近ければ更新申請を行います。[R1T5-15]
- 更新申請は満了日以前、6か月以上の在留期間であれば満了の3か月前から可能です。[R1T5-19]
- 事業主側の「中長期在留者の受入れに関する届出」は努力義務です（採用・雇用終了時）。[R1T5-16]
- 事業主は採用前に在留資格上の従事可否を確認します（告示による指針）。選考段階の確認は口頭・書面、在留カードは内定後です。[R1T4-14][R1T4-07]
- 活動を3か月（高度専門職2号は6か月）以上行わない場合、正当な理由がない限り在留資格を取り消すことができます。[R1T5-14]

### 3. 就労資格証明書

- 入管法 19条の2: 申請があった場合に交付することが「できる」。活動が明らかであるにもかかわらず、不提示を理由に不利益な取扱いをしてはなりません。[R1T4-19]
- 対象は就労が認められた外国人、申請者は本人（代理人・取次者も可）、手数料2,000円（オンライン1,600円）。転職により勤務先が変わった人向けの書類セットが別にあります。[R1T5-18]
- 用途: 採用後の業務が現在の資格の活動に該当するかを確認できます（ISA Q&A Q3）。[R1T5-17]

### 4. 高度専門職ポイントの概要

- 2012-05-07 導入。イ（研究）・ロ（専門・技術）・ハ（経営・管理）の3類型で、学歴・職歴・年収等の合計が70点以上であれば優遇されます。[R1T5-22]
- ロ・ハは年収300万円以上が最低基準です。JLPT N1 のボーナス15点、N2 10点。[R1T5-25]
- 1号の優遇: 在留期間5年の一律付与、永住要件の緩和（3年、80点以上は1年）、配偶者の就労、親・家事使用人の条件付き帯同、優先審査。[R1T5-23]
- 2号: 就労資格の活動のほぼすべて、在留期間は無期限。[R1T5-24]
- **1号の転職（所属機関の変更）には在留資格変更許可申請が必要です。** [R1T5-26]

### 5. 就労制限のない資格

- 19条1項の活動制限は別表第一の資格にのみ適用されます。[R1T5-20]
- 別表第二は永住者（無期限）・日本人の配偶者等・永住者の配偶者等・定住者の4種です。[R1T5-21]
- 告示による指針も、永住者・定住者等には活動制限がないと記しています。[R1T4-15]

### 7. 面接の定型質問と中立的な回答構造（設計案）

質問の頻度については公的・実証的な資料がありません（未確認）。以下の質問・例文は、上記の事実をもとに私たちが新たに作成したものです。回答構造は R1-T4 §「在留資格と期限は?」（①資格名 ②期限 ③就労可能であるという認識 ④届出は本人）に従い、変形のみを追加します。

| 質問（私たちが作成した日本語） | 回答構造 | 根拠 |
|---|---|---|
| 在留資格と期限を教えてください。| ①資格名 ②満了年月 ③この職務が資格の範囲内であるという認識 ④転職の届出は本人が14日以内に | [R1T5-01][R1T5-11][R1T4-07] |
| 転職するとビザの手続きは必要ですか。| 技人国の継続: 変更不要・本人が届出 / 満了3か月以内なら更新 / 証明書は任意、会社が希望すれば協力 | [R1T5-15][R1T5-19][R1T4-19] |
| （高度専門職1号） 入社はいつから可能ですか。| 変更許可が必要であるという事実 → 許可後に入社 → 申請の準備状況 | [R1T5-26] |
| 前職を辞めてからどのくらいですか。| 退職日 → 現在の状況を事実のみで。「正当な理由」への該当性はコーチが判断しない | [R1T5-14][R1T5-29] |
| （永住者等） 就労に制限はありますか。| 資格名 + 「就労制限はありません」 の1文 | [R1T5-20][R1T5-21] |
| 在留カードを見せていただけますか。（選考段階） | 資格名・期限を口頭で答え、カードの写しは内定後の依頼に応じると丁寧に | [R1T4-07][R1T5-31] |
| 通訳業務になりますが日本語の資格は? | 試験名・級・取得年。カテゴリー3・4の場合は更新時に B2 の証明が必要になる可能性あり | [R1T5-09][R1T5-10] |

例文（私たちが作成）:
- 「在留資格は技術・人文知識・国際業務で、期限は2028年3月です。御社の業務は今の資格の範囲内と理解しており、転職の届出は入社後14日以内に私が行います。」
- 「現在は高度専門職1号のため、転職には在留資格の変更許可が必要です。許可が出てから入社する形になります。」
- 「前職は9月末に退職し、現在は転職活動中です。」

## パック候補

PRD §4.1 の契約。注入文字列は日本語。R1-T4 がすでに `str-visa-facts`(correction_rule)とカテゴリー `日本で働く理由・在留` を提案しているため、**重複して提案しません。** 新しい correction_rule はありません（修正前→修正後が成立する T5 固有の文型がなく、「大丈夫です」系は C2・T4 の所管）。

culture_notes（3件、合計 約190字）:
1. `就労資格証明書の取得は任意で、就労できる活動が明らかなら未提示を理由とする不利益な取扱いは法律で禁じられているため、必須書類のようには答えない。` [R1T4-19][R1T5-17][R1T5-18]
2. `前職の退職後、正当な理由なく3か月以上就労資格の活動をしないと在留資格取消しの事由になり得るため、退職日と現状は事実だけを短く述べる。` [R1T5-14]
3. `高度専門職1号の転職は届出だけでなく在留資格変更許可が必要なため、入社可能時期は許可後として答える。` [R1T5-26]

doc_only（今回のマージから除外）:
- 技人国の3経路（大卒・専修学校・10年）、国際業務3年、報酬の同等性、関連性の判断 [R1T5-03]~[R1T5-07]: 質問生成時の「専攻と職務の関係」に関する質問の背景。コーチが許可の可能性を判定すると法律相談になるため、注入しません。
- カテゴリー3・4 言語業務 B2 [R1T5-09][R1T5-10]: 2026-04 の新設のため変動の可能性が高い。注入前に再確認が必要です。
- 届出の罰則・変更審査での考慮 [R1T5-08][R1T5-13]、更新は3か月前から [R1T5-19]、高度専門職のポイント・優遇 [R1T5-22]~[R1T5-25]、別表第二 [R1T5-20][R1T5-21]。
- §7 の質問表: `question_taxonomy` に enum を追加せず、T4 の `日本で働く理由・在留` カテゴリーの下で質問生成のヒントとして使います。

レビューメモ: 3件とも出身に依存するルールではありません（置換テスト通過: 在留資格を持つ全員に該当）。欠如テスト: 候補者の不足を含意しません。culture_note 2 は「取り消される」ではなく「事由になり得る」として、法律条文の裁量的な表現を維持しました。
