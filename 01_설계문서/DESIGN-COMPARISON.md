# Built with Claude 提出案の比較（1枚まとめ）

最終選択は選考結果（10/30）の後にユーザーが決定。設計書: DESIGN-KAKAOTALK-INTERVIEW-COACH.md / DESIGN-INTL-MAIL-AGENT.md

| 項目 | A. カカオトーク面接コーチ | B. 国際郵便シンプル処理エージェント |
|---|---|---|
| 一言 | カカオトークの会話で日本の転職面接の質問を練習 + ビジネス日本語の添削 | 国際郵便の写真を判別・要約し、期限と行動チェックリストまで整理 |
| 対象 | 日本で転職する韓国人・外国人の求職者 | 海外在住の外国人全体（国の拡張が可能） |
| 中核資産 | 本人の実際の添削ルールDBと面接の実例 — 真似できないデータ | 日本の郵便・税関手続きのナレッジベース + 判別スキーマ |
| 差別化ポイント | 「日本語の添削」ではなく「回答構成のコーチング」（質問に答えたかのチェック） | 「翻訳」ではなく「判別 → 期限 → 行動」まで完結するエージェント |
| 審査テーマとの整合 | 専門性の活用 + 技術の壁の解消 | 日常の不便 + 言語の壁の解消、社会的文脈が広い |
| デモのインパクト | 対話型なので実演が自然で、ビフォー/アフターが鮮明 | 写真1枚 → カードの結果、直感的で汎用的 |
| 実装難易度 | 中 — 対話ループとルールDBが中心、画像認識は不要 | 中 — 画像の読み取り精度が成否を左右 |
| 主なリスク | 対象が狭く見える可能性、カカオトークとの実際の連携は拡張段階 | 金額・期限の誤認識のリスク（確認フラグで緩和） |
| 8日間の日程の余裕 | 余裕あり（ルール・プロンプト中心） | 普通（文書の種類別の精度テストに時間が必要） |
| 大会後の活用 | 同じ課題を持つ外国人求職者への展開 + 商品化が可能 | 本人の生活で常時使用 + 在住外国人コミュニティへの拡散 |

## 決定ガイド
- **「自分の専門性と実データで勝負」**→ A。完成度と説得力が最も高く、日程のリスクが低い
- **「広い問題定義と汎用性で勝負」**→ B。多くの審査員の共感を早く得られ、社会性のアピールが強い
- 混合戦略も可能: A を本選出品作とし、発表で B をロードマップとして提示（逆も可能）— ただし、制作は1つに集中
