| 항목 | A. 카카오톡 면접 코치 | B. 국제우편 단순처리 에이전트 |
|---|---|---|

| 대상 | 일본에서 이직하는 한국인·외국인 구직자 | 해외 거주 외국인 전체 (국가 확장 가능) |

| 심사 테마 정합 | 전문성 활용 + 기술 장벽 제거 | 일상 불편 + 언어 장벽 제거, 사회 맥락이 넓음 |
| 데모 임팩트 | 대화형이라 시연이 자연스럽고 비포/애프터가 선명 | 사진 한 장 → 카드 결과, 직관적이고 범용적 |
| 구현 난이도 | 중 — 대화 루프와 규칙 DB 중심, 비전 불필요 | 중 — 비전 판독 정확도가 성패 좌우 |
| 주요 리스크 | 대상이 좁아 보일 수 있음, 카톡 실제 연동은 확장 단계 | 금액·기한 오인식 위험 (확인 플래그로 완화) |
| 8일 일정 여유 | 여유 있음 (규칙·프롬프트 중심) | 보통 (문서 종류별 정확도 테스트 시간 필요) |
| 대회 후 활용 | 본인 이직 활동에 즉시 실사용 + 상품화 가능 | 본인 생활에 상시 사용 + 거주 외국인 커뮤니티 확산 |

## 결정 가이드
- **"내 전문성과 실데이터로 승부"** → A. 완성도와 설득력이 가장 높고, 일정 리스크가 낮음
- **"넓은 문제 정의와 범용성으로 승부"** → B. 심사위원 다수에게 공감이 빠르고 사회성 어필이 강함
- 혼합 전략도 가능: A를 본선출작으로 하되 발표에서 B를 로드맵으로 제시 (반대도 가능) — 단, 제작은 하나에 집중
