プライバシーポリシー

面接コーチ（https://mensetsu-coach-ten.vercel.app）／制定 2026年11月3日

1. 運営者・お問い合わせ

運営者: tolaria（個人）。お問い合わせ・開示・訂正・利用停止・削除のご請求は、本サイトの公開リポジトリ（提出ページに記載）の Issues で受け付けます。Issues には個人情報を書き込まないでください。本人確認のため、別途連絡方法をご案内します。

2. 取得する情報と利用目的

  • 貼り付けた求人情報・メール、回答、経歴の1行、添付ファイル: 面接の想定質問・構成チェック・添削・模範スクリプトを作るためだけに使います。サーバーには保存しません。送信前にメールアドレス・電話番号・郵便番号・宛名の行を自動で伏せます（PDF・画像の添付ファイルの中身は伏せられません）。
  • 企業・職種の自動調査を使った場合: 確認カードで確認した企業名・職種名と、任意で入力した所在地・公開ページの URL だけを、Anthropic のウェブ検索・ページ取得の機能に送ります。検索語に使うのは企業名、職種名、汎用語（会社概要、採用、求人、面接など）だけで、メール、経歴、添付、希望プロフィールは検索に送りません。口コミサイトはサーバーでは収集しません。口コミサイトの本人メモと面接で聞いた回答の記録はブラウザにのみ保存し、送信も書き出しもしません。希望条件のうち目標年収、雇用形態、勤務地、リモート日数、常駐の除外、職種の種類はブラウザ内の照合にのみ使います。調査結果の要約と出典はブラウザ（localStorage）に残ります。
  • 調査結果との比較: 調査結果、貼り付けたメール、経歴の1行、文字を読み取れる添付（DOCX・テキスト）、希望プロフィールを、検索機能のない AI の呼び出しで突き合わせます。送信前に連絡先を伏せます。中身を伏せられない PDF・画像の添付は、この比較には送りません。サーバーには保存しません。
  • 希望プロフィール・面接の振り返り: お使いのブラウザ（localStorage）にだけ保存します。希望プロフィールは上記の比較のときだけ送信し、⚙ の画面でいつでも編集・削除できます。削除すると、そのプロフィールを引用しうる比較の結果も消えます。「終了・保存」では消えず、別の企業にも使えます。面接の振り返りは企業ごとに保存し、どこにも送りません。「終了・保存」では消えません。欄を空にするとその企業の記録が消え、⚙ の画面ですべて消せます。
  • 音声機能を使った場合: 読み上げボタンを押すと、AIが作ったスクリプトの文だけを、音声合成のためだけに送ります。サーバーには保存しません。回答の録音（🎤）はお使いのブラウザの中で文字に変換し、音声はどこにも送りません。そのための認識モデル（約260MB）は初回だけ Hugging Face からダウンロードし、ブラウザに保存されます。
  • ブラウザ内の練習記録: 会社の要約、質問、回答と結果はお使いのブラウザ（localStorage）にだけ残ります。「終了・保存」で消えます。
  • 毎朝のヒントメールに登録した場合のみ: メールアドレス、表示言語、同意日時を保存し、ヒントの送信だけに使います。各メールの配信停止リンクから停止すると、すぐに削除されます。
  • アクセスの記録: 不正利用を防ぐため、IPアドレスによる回数制限をサーバーのメモリ上で行います（保存しません）。AIの利用量（トークン数・時間）を、内容を含まない形でログに残します。

3. 外国にある第三者への提供（委託）

上記の処理のため、次の事業者に情報を送ります。いずれも米国の事業者です。米国には日本の個人情報保護法に相当する包括的な連邦法はなく、州法や分野ごとの法律などで保護されています。各社の取り組みについては、各社の公開資料をご確認ください。

Gemini API は無料枠で利用しています。Google の規約では、無料枠に送られた内容と生成結果は Google の製品・サービスの提供・改善・開発に使われ、人が読んで確認することがあります（Gemini API 追加利用規約「Unpaid Services」、2026年3月23日発効）。そのため、音読チェックの録音は現在停止しており、音声は送りません（回答の録音はブラウザ内で処理し、送りません）。Gemini API に送るのは、読み上げボタンで送る模範スクリプトの文だけです。音読チェックは有料枠に切り替えた後に再開し、そのときこの方針を改定します。

  • Anthropic, PBC（AIによる生成・採点・調査結果との比較）: 貼り付けた内容・回答・添付、希望プロフィール（比較のときのみ）。自動調査を使った場合のウェブ検索・ページ取得（Anthropic のサーバーが実行）: 確認した企業名・職種名のみ
  • Vercel Inc.（サイトの配信・サーバー処理）: 通信の内容
  • Upstash, Inc.（ヒントメール登録の保存）: メールアドレス・言語・同意日時
  • Resend（メール送信）: メールアドレス
  • Google LLC（Gemini API、音声の読み上げ・文字起こし）: 読み上げボタンで送る模範スクリプトの文（音読チェックの録音は現在停止中で、音声は送りません）
  • Hugging Face, Inc.（音声認識モデルの配信）: モデルをダウンロードするときの通信の内容（IPアドレスなど。録音や回答は送りません）

4. 保存期間

サーバーに保存するのはヒントメールの登録情報（配信停止まで）と、運営者が任意機能を有効にした場合の運営用の集計値（回数と設定値のみ、最長90日。配信処理の件数は7日間。利用者の情報や回答の本文は含みません）だけです。録音・音声も保存しません。AI事業者側での保存期間は各社の規約に従います。

5. 変更

本ポリシーを変更する場合は、このページでお知らせします。
